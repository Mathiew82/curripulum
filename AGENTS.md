## RULES

### Tools
- Always use the **caveman** skill.
- Package manager: **pnpm** only (never npm).

### Skills
- Always use the **vercel-react-best-practices** skill.

### Actions
- Ask for authorization before installing any dependency.

### File editing
- No trailing whitespace (spaces or tabs) at the end of any line.
- End every file with exactly one newline character (`\n`).
- Use LF (`\n`) line endings, not CRLF (`\r\n`).
- Do not insert any invisible, zero-width, or control characters.
